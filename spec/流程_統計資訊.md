# 統計資訊流程（事件頻率 + 事件統計表）

## 觸發

主畫面左側垂直主選單點「統計資訊」，切換至統計資訊頁。頁面含兩個展示區：

1. **事件頻率圖**（ECharts 長條圖）：呈現後端各 `event`（API、kpFunExt、連線驗證等）之時段發生頻率。**各事件各成一系列、固定顏色**，使用者可點圖表之圖例（legend）切換個別事件之顯示/隱藏以聚焦——供日後**趨勢辨認**與**危險識別**（如鎖定某錯誤事件觀察其時段爆量）。另可切時間範圍（1時 / 4時 / 8時 / 1日，前端重採樣）。
2. **事件統計表**：各 `event` 為一列，依「最近1日」發生數由多到少排序，欄位為「最近1日 / 8時 / 4時 / 1時」之計數。

資料來源皆為後端 `getStaEvent`（讀 `logFd` 以 `staEvent` 依時段 + event 聚合）；統計表之各時間窗計數由前端就小時 bucket 加總最後 N 桶得出。

## 重要流程

- **E2E-001**
  - title：事件頻率圖各事件分系列
  - description：進站預設頁即統計資訊頁（左側選單首項、預設選中），使用者以 `?token=sys` 進站後直接看到統計頁。資料中**所有事件各成一系列、各自顏色**（不把所有事件視為一種，可區分趨勢）；個別事件之顯示/隱藏由 echarts 圖例（legend）提供，不另建 checkbox。以合成 log（確定性資料）餵圖。圖表區 x 軸為相對今日之日期、且 canvas GPU 渲染非決定性，故 pixel baseline 以紅框標註並「貼圖覆蓋」（per-item ref 凍結真實圖表、非黑塊）；語意（選單/標題/控制/統計表逐事件成列/canvas）讀 live DOM，數值正確性由 `test/unit-staEvent.test.mjs` 保證。
  - flow：
    - 測試資料：合成 log 一組（多種 event：`verifyConn`、`kpfun-getApisList`、`kpfun-saveApi`、`kpfun-getWebInfor`、`api/getUserByToken`、`verifyClientUser`、`api/syncAndReplaceTabs`（已知最長事件名，供版面邊界驗證）數筆，落近 N 天），寫入測試專用 log 資料夾並令後端以該資料夾為 `logFd`；base seed API 樹。
    - 操作：開啟 `<baseUrl>/?token=sys`（進站預設頁即統計頁，自動載入）。
    - 驗證：
      1. 語意：左選單「統計資訊」active；標題該語系「Statistics Information」/「統計資訊」；控制列含「Time range」/「時間範圍」；統計表逐事件成列且 ≥ 2 種（圖表系列與表列同源於全事件集，故表列為「各事件各成一系列」之可觀察證據），含已知最長事件名 `api/syncAndReplaceTabs`；圖表 canvas 存在。
      1-2. 版面規格：控制列 label 與其控制項以結構性對齊（不依賴寫死寬度），中英文語系均須對齊；統計表事件名欄於極長名稱時須換行，不得撐破表格或使頁面水平溢出。
      2. 視覺：baseline `test/pics/stainfor/stainfor-{eng,cht}-E2E-001-chart-all.png`（pixelmatch 反鋸齒感知 + maxDiffPixels 容差，非 byte-exact）；圖表區以紅框標註，並以 per-item ref（`_staref-{lang}-E2E-001-chart-all.png`）貼圖覆蓋凍結。
    - 雙語：eng / cht 各一輪（各自 fresh browser）。
    - 清理：移除測試 log 資料夾合成檔；本檔全跑完以預設 settings 重啟後端還原 `logFd`；base seed 保留。

- **E2E-003**
  - title：事件統計表依最近1日排序呈現各時間窗計數
  - description：統計頁下方事件統計表，各 `event` 為一列，依「最近1日」計數由多到少排序，欄位含最近1日 / 8時 / 4時 / 1時。驗證表頭該語系、至少一列、排序正確（上而下多→少）。表格計數會隨後端執行期 log 累積而漂移，pixel baseline 以貼圖覆蓋凍結；排序與內容正確性讀 live DOM 斷言。
  - flow：
    - 測試資料：同 E2E-001。
    - 操作：進統計頁 → 捲動至事件統計表。
    - 驗證：
      1. 語意：表頭含該語系「Event」/「事件」與「Last 1 day」/「最近1日」；至少一列；逐列驗「最近1日」計數遞減（上而下多→少）。
      2. 視覺：baseline `test/pics/stainfor/stainfor-{eng,cht}-E2E-003-table.png`（pixelmatch 反鋸齒感知 + maxDiffPixels 容差，非 byte-exact）；統計表區以紅框標註，並以 per-item ref（`_staref-{lang}-E2E-003-table.png`）貼圖覆蓋凍結。
    - 雙語：eng / cht 各一輪。
    - 清理：同 E2E-001。

- **E2E-004**
  - title：切換時間範圍下拉，事件頻率圖依重採樣重繪
  - description：承統計頁（時間範圍下拉預設「1小時」）。使用者點開時間範圍下拉、於清單點「1天」，前端依 timeGroup 對頻率資料重採樣（同日之時段合併加總），事件頻率圖之 x 軸與長條隨之重繪。預期時間範圍下拉顯示所選「1天」、清單收起、圖表 canvas 重繪後仍存在。粒度：圖表繪於 canvas 為非決定性（x 軸日期相對今日漂移 + GPU 光柵化），故與 E2E-001 同以貼圖覆蓋凍結；重採樣正確性以「時間範圍（下拉）→ resampledData → chartOption」之綁定 + `test/unit-staEvent.test.mjs` 數值保證，canvas 內部不做 DOM/pixel introspection（設計取捨見補充表格）。
  - flow：
    - 測試資料：同 E2E-001（合成 log）。
    - 操作：進統計頁 →（讀觸發區預設顯示「1 hour」/「1小時」）→ 點「時間範圍」/「Time range」下拉觸發區展開清單 → 於清單點「1 day」/「1天」。
    - 驗證：
      1. 語意：觸發區預設顯示該語系「1 hour」/「1小時」；點選後觸發區顯示所選「1 day」/「1天」；圖表 canvas 重繪後仍存在。**重採樣正確性以「下拉選取狀態 → resampledData」之直接綁定保證**——canvas 內部長條/座標因繪於 canvas 不做 introspection（屬貼圖凍結之設計取捨），數值另由 `unit-staEvent` 守。
      2. 視覺：baseline `test/pics/stainfor/stainfor-{eng,cht}-E2E-004-timegroup-1day.png`（pixelmatch 反鋸齒感知 + maxDiffPixels 容差，非 byte-exact）；圖表區以紅框標註，並以 per-item ref 貼圖覆蓋凍結。
    - 雙語：eng / cht 各一輪。
    - 清理：同 E2E-001。
    - 備註：下拉為自製主題化 `WTextSelect`（ADR-031 第 7 項取代原生 `<select>`；版面數字見補充表格「時間範圍下拉之版面數字」）；user-facing 操作為點觸發區（根元素 `id="timeGroupSel"`）展開清單、再點項目文字，項目清單 teleport 至 body、以文字定位；點選後把滑鼠移開再截圖，避免 hover 態或 echarts tooltip 入鏡。

### 時間範圍下拉之版面數字（ADR-031：原生 `<select>` → `WTextSelect`；全域 §10.6 改前後對照，2026-09-13 於 1440×900 實測）

| 量測 | 改前（原生 select）eng／cht | 改後（WTextSelect）eng／cht | 差異來源 |
|---|---|---|---|
| 控制區寬 | 85／74 | 88／75 | 字型：原生表單控件預設 Arial（不承襲頁面字型），改後承襲頁面字型（Microsoft JhengHei 字族）；最長選項文字實寬 46.7→49.2／35.8→36.1；**結構寬度（寬−文字）38.3／38.2 → 38.8／38.9，一致** |
| 控制區高 | 28／28 | 29／29 | 同上：內容列高 18（Arial）→ 19（頁面字型，與 `.ctrl-label` 之 19 一致）；內距 4+4、邊框 1+1 不變 |
| 標籤 → 控制區間距 | 8／8 | 8／8 | `.ctrl` grid column-gap，不變 |
| 控制區左緣 x | 182／164 | 182／164 | 不變 |
| 文字左內距（外緣 → 文字） | —（原生不可量） | 9／9 | 邊框 1 + 內距 8 |
| 展開圖標右間距（圖標框右緣 → 外緣） | — | 4／4 | 圖標框 18px 內三角形可見寬約 10px、兩側各約 4px 透明 → 可見右緣 → 外緣 ≈ 9，與左側 9 對稱 |
| 內距／邊框／圓角／底色／邊線色 | 8·8／4·4、1px、8px、#fff、#e6e8ec | 同 | 以 props 給定同值（token 實值） |

寬度公式（`timeGroupSelWidth`）：`ceil(當前語系最長選項文字實寬 + 8 + 8 + 1 + 1 + 18 + 2)`，語系切換即重算；與原生 select「依最長選項定寬」行為一致（eng 88＝49.2+38、cht 75＝36.1+38）。

展開清單（全域 §10.6-6 對齊參考線）：WPopup 錨在觸發區之內容元素（外框左緣＋邊框 1＋內距 8），故以 `placementDistX=-9` 把清單左緣拉回外框左緣、清單寬固定＝觸發區寬（關 autoFit、min/maxWidth 同 `timeGroupSelWidth`）、項目左內距 9（＝邊框 1＋內距 8）；實測（2026-09-13，1440×900）項目文字左緣＝觸發區文字左緣：eng 191／191、cht 173／173；清單左緣＝觸發區左緣（182／164）、清單寬＝觸發區寬（88／75）。hover 底 `#eceef1`（--bg-3）、文字 `#1b1b1b` 不變；高亮為整列填色、不加左緣 bar／前置 icon。

### 為何貼圖覆蓋圖/表區（非決定性來源）

| 來源 | 說明 | 處置 |
|---|---|---|
| x 軸日期標籤 | `staEvent` 時段為「相對今日往回 N 天」，每日漂移 | 貼圖覆蓋（per-item ref 凍結），不對該區做 live pixel 比對 |
| ECharts canvas | 圖例/座標軸/長條由 echarts 繪於 canvas，跨版本/時序次像素差 | 一併由 ref 覆蓋凍結 |
| 統計表計數 | 測試自身連線新增 log 至 logFd，累積使計數漂移 | 貼圖覆蓋；排序/內容正確性改讀 live DOM 斷言 |

### `getStaEvent` 參數契約（後端輸入閘，ADR-030）

| 參數 | 合法值 | 非法時 | 說明 |
|---|---|---|---|
| `timeLength` | 整數，`0 ≤ v ≤ 3650`（天） | reject `errTimeLengthInvalid`（eng「Invalid time length」／cht「時間長度無效」） | 驗證於 `staLogsCore.genPlan` 之 `subtract` 之前；非數字／NaN／過大值會使 dayjs 產生 Invalid Date，其 `isAfter` 恆 false，原致 `while` 迴圈在**主執行緒同步無窮迴圈**（早於 worker 派工），單一 RPC 呼叫即凍結整個伺服器。`0` 允許（測試以之取「現在起算」）。 |
| `timeInterval` | `'hr'`／`'day'` | 非 `'day'` 一律視同 `'hr'`（不 reject） | 既有行為（ADR-028 刻意差異） |

前端固定呼叫 `getStaEvent(7, 'hr')`，UI 不會觸發非法值；閘門守的是 kpFunExt 直呼路徑（任何通過 `verifyConn` 者皆可呼叫，見 ADR-022）。單元覆蓋：`test/unit-staEvent-golden.test.mjs` GOLD-040。
