# 統計資訊流程（事件頻率 + 事件統計表）

## 觸發

主畫面左側垂直主選單點「統計資訊」，切換至統計資訊頁。頁面含兩個展示區：

1. **事件頻率圖**（ECharts 長條圖）：呈現後端各 `event`（API、kpFunExt、連線驗證等）之時段發生頻率。**各事件可區分選取**（每事件一系列、固定顏色），使用者可全選 / 清除 / 勾選特定事件聚焦——供日後**趨勢辨認**與**危險識別**（如鎖定某錯誤事件觀察其時段爆量）。另可切時間範圍（1時 / 4時 / 8時 / 1日，前端重採樣）。
2. **事件統計表**：各 `event` 為一列，依「最近1日」發生數由多到少排序，欄位為「最近1日 / 8時 / 4時 / 1時」之計數。

資料來源皆為後端 `getStaEvent`（讀 `logFd` 以 `staEvent` 依時段 + event 聚合）；統計表之各時間窗計數由前端就小時 bucket 加總最後 N 桶得出。

## 重要流程

- **E2E-001**
  - title：事件頻率圖各事件分系列（預設全選）
  - description：進站預設頁即統計資訊頁（左側選單首項、預設選中），使用者以 `?token=sys` 進站後直接看到統計頁。預設**全選所有事件**，頻率圖以「各事件一系列、各自顏色」呈現（不把所有事件視為一種，可區分趨勢）。以合成 log（確定性資料）餵圖。圖表區 x 軸為相對今日之日期、且 canvas GPU 渲染非決定性，故 pixel baseline 以紅框標註並「貼圖覆蓋」（per-item ref 凍結真實圖表、非黑塊）；語意（選單/標題/控制/全選狀態/canvas）讀 live DOM，數值正確性由 `server/staLogs/test_staEvent.mjs` 保證。
  - flow：
    - 測試資料：合成 log 一組（多種 event：`verifyConn`、`kpfun-getApisList`、`kpfun-saveApi`、`kpfun-getWebInfor`、`api/getUserByToken`、`verifyClientUser`、`api/syncAndReplaceTabs`（已知最長事件名，供版面邊界驗證）數筆，落近 N 天），寫入測試專用 log 資料夾並令後端以該資料夾為 `logFd`；base seed API 樹。
    - 操作：開啟 `<baseUrl>/?token=sys`（進站預設頁即統計頁，自動載入）。
    - 驗證：
      1. 語意：左選單「統計資訊」active；標題該語系「Statistics Information」/「統計資訊」；控制列含「Select events」/「選擇事件」與「Time range」/「時間範圍」；事件 checkbox ≥ 2 且**預設全部勾選**（各事件分系列）；圖表 canvas 存在。
      1-2. 版面幾何（本流程之版面規格，於主視窗與窄視窗兩檔各驗一次）：事件名不得截字（除非單一 chip 已達容器寬上限之安全閥情境）；chip 區容器須用滿控制區可用寬（右界貼齊）；換列須因真的排不下（非被人為寬度上限切斷）；chip 區不得水平溢出。
      2. 視覺：baseline `test/pics/stainfor/stainfor-{eng,cht}-E2E-001-chart-all.png`（pixelmatch 反鋸齒感知 + maxDiffPixels 容差，非 byte-exact）；圖表區以紅框標註，並以 per-item ref（`_staref-{lang}-E2E-001-chart-all.png`）貼圖覆蓋凍結。
    - 雙語：eng / cht 各一輪（各自 fresh browser）。
    - 清理：移除測試 log 資料夾合成檔；本檔全跑完以預設 settings 重啟後端還原 `logFd`；base seed 保留。

- **E2E-002**
  - title：選取部分事件，圖表只顯示所選
  - description：承統計頁，使用者按「清除」後僅勾選特定事件（如 `verifyConn`、`kpfun-getApisList`），頻率圖只保留所選事件之系列——驗證「事件可區分聚焦」（危險識別時只看關注事件）。圖表區同 E2E-001 為非決定性，pixel baseline 一樣貼圖覆蓋。
  - flow：
    - 測試資料：同 E2E-001。
    - 操作：進統計頁 → 按「Clear」/「清除」→ 勾選 `verifyConn`、`kpfun-getApisList` 兩事件。
    - 驗證：
      1. 語意：勾選之事件恰為所選兩者（其餘未勾）；圖表 canvas 仍存在（重渲染後）。**圖表系列正確性以「選取狀態（checkbox）→ 系列」之直接綁定保證**——`seriesKeys` computed 即等於 `selectedEvents`，故驗證 checkbox 即等同驗證系列集合；canvas 內部系列數/內容因繪於 canvas 不做 DOM/pixel introspection（屬貼圖凍結之設計取捨，見補充表格），數值另由 `test_staEvent` 守。
      2. 視覺：baseline `test/pics/stainfor/stainfor-{eng,cht}-E2E-002-chart-selected.png`（pixelmatch 反鋸齒感知 + maxDiffPixels 容差，非 byte-exact）；圖表區以紅框標註，並以 per-item ref 貼圖覆蓋凍結。
    - 雙語：eng / cht 各一輪。
    - 清理：同 E2E-001。

- **E2E-003**
  - title：事件統計表依最近1日排序呈現各時間窗計數
  - description：統計頁下方事件統計表，各 `event` 為一列，依「最近1日」計數由多到少排序，欄位含最近1日 / 8時 / 4時 / 1時。驗證表頭該語系、至少一列、排序正確（上而下多→少）。表格計數會隨後端執行期 log 累積而漂移，pixel baseline 以貼圖覆蓋凍結；排序與內容正確性讀 live DOM 斷言。
  - flow：
    - 測試資料：同 E2E-001。
    - 操作：進統計頁 → 捲動至事件統計表。
    - 驗證：
      1. 語意：表頭含該語系「Event」/「事件」與「Last 1 day」/「最近1日」；至少一列；逐列驗「最近1日」計數遞減（上而下多→少）。
      2. 視覺：baseline `test/pics/stainfor/stainfor-{eng,cht}-E2E-003-table.png`（pixelmatch 反鋸齒感知 + maxDiffPixels 容差，非 byte-exact）；統計表區以紅框標註，並以 per-item ref（`_staref-{lang}-E2E-003-table.png`）貼圖覆蓋凍結。
    - 雙語：eng / cht 各一輪。
    - 清理：同 E2E-001。

- **E2E-004**
  - title：切換時間範圍下拉，事件頻率圖依重採樣重繪
  - description：承統計頁（時間範圍下拉預設「1小時」）。使用者將時間範圍下拉切為「1天」，前端依 timeGroup 對頻率資料重採樣（同日之時段合併加總），事件頻率圖之 x 軸與長條隨之重繪。預期時間範圍下拉顯示所選「1天」、圖表 canvas 重繪後仍存在。粒度：圖表繪於 canvas 為非決定性（x 軸日期相對今日漂移 + GPU 光柵化），故與 E2E-001/002 同以貼圖覆蓋凍結；重採樣正確性以「時間範圍（下拉）→ resampledData → chartOption」之綁定 + `server/staLogs/test_staEvent.mjs` 數值保證，canvas 內部不做 DOM/pixel introspection（同 E2E-002 之設計取捨，見補充表格）。
  - flow：
    - 測試資料：同 E2E-001（合成 log）。
    - 操作：進統計頁 →（將「時間範圍」/「Time range」下拉切為「1 day」/「1天」）。
    - 驗證：
      1. 語意：時間範圍下拉值為「1天」（顯示該語系「1 day」/「1天」）；圖表 canvas 重繪後仍存在。**重採樣正確性以「下拉選取狀態 → resampledData」之直接綁定保證**——canvas 內部長條/座標因繪於 canvas 不做 introspection（屬貼圖凍結之設計取捨），數值另由 `test_staEvent` 守。
      2. 視覺：baseline `test/pics/stainfor/stainfor-{eng,cht}-E2E-004-timegroup-1day.png`（pixelmatch 反鋸齒感知 + maxDiffPixels 容差，非 byte-exact）；圖表區以紅框標註，並以 per-item ref 貼圖覆蓋凍結。
    - 雙語：eng / cht 各一輪。
    - 清理：同 E2E-001。

## 補充表格

### 為何貼圖覆蓋圖/表區（非決定性來源）

| 來源 | 說明 | 處置 |
|---|---|---|
| x 軸日期標籤 | `staEvent` 時段為「相對今日往回 N 天」，每日漂移 | 貼圖覆蓋（per-item ref 凍結），不對該區做 live pixel 比對 |
| ECharts canvas | 圖例/座標軸/長條由 echarts 繪於 canvas，跨版本/時序次像素差 | 一併由 ref 覆蓋凍結 |
| 統計表計數 | 測試自身連線新增 log 至 logFd，累積使計數漂移 | 貼圖覆蓋；排序/內容正確性改讀 live DOM 斷言 |
